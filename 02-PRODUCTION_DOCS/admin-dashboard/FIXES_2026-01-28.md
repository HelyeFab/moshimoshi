## Technical Implementation

### View Tracking System

**Architecture**:
```
User views content
    ↓
Content served (cache OR network)
    ↓
Client calls POST /api/track-view
    ↓
Server increments viewCount atomically
    ↓
Deduplication check (3s window per user)
```

**Endpoint**: `POST /api/track-view`

**Request Body**:
```typescript
{
  contentType: 'books' | 'stories' | 'comics' | 'news_articles',
  contentId: string
}
```

**Response**:
```typescript
{
  success: true,
  message: 'View tracked',
  contentType: string,
  contentId: string,
  deduplicated?: boolean  // If duplicate detected
}
```

**Key Features**:
- ✅ Atomic increments (`FieldValue.increment(1)`)
- ✅ Per-user deduplication (prevents React Strict Mode double-counting)
- ✅ Works with PWA offline caching
- ✅ Multiple users can view same content simultaneously
- ✅ Non-blocking (doesn't slow down content delivery)

**Deduplication Logic**:
```typescript
// In-memory cache with 3-second window
const recentViews = new Map<string, number>();
const DEDUP_WINDOW_MS = 3000;

function isDuplicateView(userId: string, contentType: string, contentId: string): boolean {
  const key = `${userId}:${contentType}:${contentId}`;
  const lastView = recentViews.get(key);
  const now = Date.now();

  if (lastView && (now - lastView) < DEDUP_WINDOW_MS) {
    return true; // Duplicate within window
  }

  recentViews.set(key, now);
  return false;
}
```

### Subscription Data Structure

**Location**: `users/{uid}/subscription`

**Structure**:
```typescript
{
  subscription: {
    status: 'active' | 'canceled' | 'past_due',
    plan: 'free' | 'premium_monthly' | 'premium_yearly',  // ← This is the field!
    stripeCustomerId: string,
    stripeSubscriptionId: string,
    stripePriceId: string,
    currentPeriodEnd: Timestamp,
    cancelAtPeriodEnd: boolean,
    metadata: {
      createdAt: Timestamp,
      updatedAt: Timestamp,
      source: 'stripe' | 'admin'
    }
  }
}
```

**Getting User Tier** (`src/lib/auth/tier-utils.ts:14-31`):
```typescript
export function getUserTier(userData: any): UserTier {
  // Check subscription.status and subscription.plan
  if (userData?.subscription?.status === 'active' && userData?.subscription?.plan) {
    const plan = userData.subscription.plan;
    if (plan === 'premium_monthly' || plan === 'premium_yearly') {
      return plan;  // ✅ Returns the actual plan
    }
  }

  // Fallback to legacy tier field (backward compatibility)
  if (userData?.tier) {
    return userData.tier;
  }

  return 'free';
}
```

**MRR Calculation** (`src/app/api/admin/stats/route.ts:63-76`):

import { getUserTier, isPremiumUser } from '@/lib/auth/tier-utils'

usersSnapshot.forEach(doc => {

  }

## Known Limitations

### View Tracking:
- Deduplication is in-memory (resets on server restart)
- 3-second window may miss some rapid double-clicks (acceptable)
- Relies on client calling track-view (could be blocked by ad-blockers)

### MRR Calculation:
- Assumes subscription data is always in `subscription.plan`
- Legacy `tier` field used as fallback only
- Does not account for discounts/coupons in display (though they're in data)
