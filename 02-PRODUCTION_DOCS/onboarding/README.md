# Developer Onboarding

**Status:** ACTIVE
**Last Updated:** 2026-02-12

## Overview
This folder provides onboarding materials for new developers joining the Moshimoshi codebase. The goal is to get a new engineer productive quickly while preserving production conventions, safety constraints, and architectural intent.

## Quick Start
1. Read `NEW_DEVELOPER_ONBOARDING.md` end-to-end.
2. Set up local environment using `ENV_LOCAL_BACKUP.md` and `.env.local` guidance.
3. Skim the production docs index to map the system areas you will touch.
