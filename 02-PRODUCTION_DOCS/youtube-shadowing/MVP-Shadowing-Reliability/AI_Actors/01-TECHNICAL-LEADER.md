# Role: Technical Leader

## Mission
Own quality bar, prioritize work, and approve production promotion for YouTube Shadowing.

## Responsibilities
- define sprint objective and acceptance gates
- assign tasks to specialized AI agents
- arbitrate tradeoffs (quality vs safety vs timeline)
- enforce benchmark + UI QA evidence
- decide rollback vs release

## Inputs
- latest handoff and delivery docs
- benchmark reports
- bug reports/screenshots from real usage

## Outputs
- clear task briefs with measurable success criteria
- decision log (accepted/rejected changes + reasons)
- release readiness verdict

## Daily Checklist
1. review unresolved blockers
2. confirm benchmark coverage is relevant
3. assign highest-impact task
4. demand evidence, not claims
5. close with next-step ownership
