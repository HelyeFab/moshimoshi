# Community Integration

**Status:** ACTIVE
**Last Updated:** 2026-01-28

## Overview

Moshimoshi's community features integrate Discord for real-time user interaction, support channels, and community engagement. The Discord server provides structured channels for different learning levels, feature discussions, and community support.

## Quick Start

1. **Review Discord setup**: See `DISCORD_COMMUNITY_SETUP.md` for server configuration
2. **Bot integration**: Configure Discord bot for automated features
3. **Channel structure**: Organized by JLPT levels and feature areas
4. **Moderation**: Set up roles and permissions for community management

## Key Features

- **Automated announcements** - Feature updates pushed to Discord
- **User verification** - Link Discord accounts to Moshimoshi profiles
- **Community events** - Scheduled learning challenges and activities
- **Support channels** - Direct help from team and community
- **Resource sharing** - Study materials and tips

## Integration Points

- Feature announcements sync to Discord
- User achievements can be shared to Discord
- Support tickets can be created from Discord
- Community challenges tracked in app
